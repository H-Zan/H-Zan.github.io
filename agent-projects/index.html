P1-01 ⏱ 7 min

Project 1 · Step 1：先访谈再建基——用 /grill-me、AGENTS.md 与 Docker PG 搭好起跑线

新手最容易一上来就让 Agent “帮我写整个全栈项目”导致直接烂尾。本节手把手带你走好前 15 分钟：用反向访谈砍掉多余功能、写下 30 行 AGENTS.md 铁律，并用 Docker + uv 跑通空项目骨架与第一条绿灯测试。

Project 1 · Step 2：小步原子实施——FastAPI + pgvector 混合检索后端与暗色前端联调

学会用“垂直切片 + 每片换干净会话”高效指挥 Agent 写代码：先切片 A 跑通入库与单 SQL RRF 混合检索接口，再切片 B 靠 Design Tokens 做出告别 AI 模板味的极简暗色前端。
P1-03 ⏱ 6 min

Project 1 · Step 3：确定性验证与交付——curl/截图自检闭环、独立审查与发布复盘

跑通单测只是及格，真正让 Agent 交付达到“资深工程师水准”的是最后 10 分钟：真接口端到端冒烟、截图视觉挑刺、另开只读会话对抗审 Diff，以及把踩过的坑沉淀回 AGENTS.md。

Project 2 · Step 1：单循环底座——Pydantic 工具注册表、步数熔断与 JSONL Trace

Project 3：存量复杂老仓库安全改造（只读隔离调研 + 特性测试 + 零事故重构）

解决真实工作中“老代码一改就崩”的噩梦：只读 Subagent 摸底划红线 → 先立保护网 → Worktree 最小变更重构 → 独立会话审 Diff 发布。

P3-01 ⏱ 7 min

Project 3 · Step 1：只读 Subagent 隔离摸底——给老仓库划红线、建 AGENTS.md 与 work.md

接手一个跑了五六年、没人写文档的存量老仓库，千万别一上来就动代码！本节教你用只读调研摸清隐藏环境坑（依赖/构建/线上发布分支），并写下保命的 AGENTS.md 禁区红线。
P3-02 ⏱ 7 min

Project 3 · Step 2：先立保护网再动刀——特性回归测试、最小变更重构与防上下文腐烂

老代码重构最大的翻车点是“顺手改坏了原本跑得很好的旧功能”。本节教你先用特性测试锁死旧行为，在独立 Git Worktree 里做最小变更手术，以及卡壳 2 轮时如何果断止损重开。
P3-03 ⏱ 6 min

Project 3 · Step 3：独立对抗审查与零停机发布——Diff 审计、线上冒烟与踩坑沉淀

老仓库安全上线的最后三道保险：用全新只读会话审查全部 git diff、上线后立即跑脚本校验线上 HTTP 200 与关键产物，并把本次排查到的隐蔽坑极简沉淀回 AGENTS.md。
