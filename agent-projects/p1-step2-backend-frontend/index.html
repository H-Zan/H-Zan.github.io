中文

Step 1 的聊天窗口里充满了 Docker 调试和方案讨论记录，现在它们已经成为噪声。核心习惯：每进入一个新切片，立刻开新会话（agy 按 Ctrl+D 重启 / Claude Code 敲 /clear），让 Agent 只读清爽的 AGENTS.md + work.md 轻装上阵！
