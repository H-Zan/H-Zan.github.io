⚠️防上下文腐烂止损线 / The 2-Strike Reset Rule

如果在老仓库里修一个兼容性问题连续 2 轮越修报错越多，立刻叫停！执行 git checkout -- . 恢复干净状态，把刚刚排查到的真正根因写成 3 句话，开一个全新会话直接喂给它——干净上下文往往 1 轮秒解！
