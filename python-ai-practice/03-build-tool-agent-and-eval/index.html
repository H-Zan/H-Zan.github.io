🔑核心工程理念 / Core Engineering Principle

没有自动化 Eval 的 AI 应用就像没有单元测试的支付系统——改了一句 Prompt，表面看着更好了，暗地里可能把 3 个核心场景改崩了。本课把 Agent 运行时和 Eval 守门测试一次配齐。
